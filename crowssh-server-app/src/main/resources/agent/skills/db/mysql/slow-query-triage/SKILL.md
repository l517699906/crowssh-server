# MySQL 慢查询排查

1. 明确用户观察到的时间、目标库和查询；没有 SQL 时先使用 inspectInstance 与有界 inspectProcessList 建立采样证据，不读取原始进程 SQL。
2. 区分启动后累计计数与瞬时值。只有两次真实采样且时间间隔明确时才能计算变化率；缺指标或分母为零时说明无法计算。
3. 使用 describeTable 核对相关字段和索引。表行数与容量是估算，不能当作实时精确值。
4. 用户提供的查询只有通过业务列授权后才能调用 explainQuery；不使用 EXPLAIN ANALYZE，不执行未授权 SELECT，不用 COUNT 或条件探测绕过范围。
5. 结合访问方式、选中索引和估算行数说明假设、证据及验证方法。执行计划没有实际运行时间，不据此宣称问题已解决。
6. 索引或 SQL 修改先说明影响，受支持的写操作必须走 executeQuery 审批。审批拒绝、过期、取消或绑定失效后停止本轮工具调用。

结果未知时禁止自动重试写入。输出被截断或能力不可用时保留这一限制，不以另一个工具获取被省略信息。
