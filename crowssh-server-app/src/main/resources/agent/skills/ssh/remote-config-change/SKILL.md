# 远程配置变更

配置变更属于写操作。除非用户在当前消息中已明确授权具体文件和目标，否则只完成读取、差异分析和变更计划。

1. 用 `statRemotePath` 确认目标路径和元数据，用 `readRemoteText` 分页读取必要内容。不得读取或回显凭据、私钥、`.env` 等受限内容。
2. 如有现有备份或候选文件，用 `compareRemoteTexts` 获取首个差异和版本信息；不要凭记忆重写整份配置。
3. 给出最小变更、影响范围、验证命令和回滚路径。覆盖、删除、批量替换或凭据处理必须在临执行前再次确认。
4. 获得确认后，通过 `executeCommand` 在目标文件同目录创建临时文件，保留原文件的所有者和权限，先运行语法校验，再原子替换。任何一步失败都停止，不继续重启或 reload。
5. 替换后重新读取必要片段或比较版本，并运行软件自带的配置校验。需要 reload/restart 时单独说明影响并确认授权。
6. 最终报告备份位置、实际差异、校验退出码、服务状态和回滚方式。只有写入与验证都明确成功时才报告完成。

不要在命令或输出中暴露秘密，不要用不受限的递归替换，也不要把工具拒绝当作改用 Shell 绕过限制的理由。
