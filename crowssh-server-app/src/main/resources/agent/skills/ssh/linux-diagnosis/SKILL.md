# Linux 主机诊断

按“建立基线、缩小范围、验证结论”的顺序排查，不在证据不足时修改系统。

1. 调用 `inspectSystem` 获取系统、内核、负载、CPU、内存和文件系统基线。
2. 磁盘或 inode 异常时，调用 `inspectDisk` 检查用户指定的绝对路径；没有指定路径时从 `/` 开始。
3. 端口或连通性异常时，调用 `inspectNetwork`；已知端口时传入单个端口以减少输出。
4. 只有结构化结果不足以定位进程、日志或内核事件时，才用 `executeCommand` 执行最小范围的只读命令。限制输出行数，不扫描无关目录。
5. 将现象、工具证据、最可能原因和仍未确认的信息分开报告。命令超时、退出码未知或非零时，不得宣称结论已验证。
6. 若修复需要安装软件、调整内核参数、清理文件、终止进程或重启服务，先说明影响并取得确认，再执行一个变更并单独验证。

不要用写操作“试试看”，不要读取凭据或私钥，也不要通过其他命令绕过工具的敏感路径和危险命令限制。
